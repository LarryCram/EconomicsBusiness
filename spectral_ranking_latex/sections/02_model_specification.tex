% ---------------------------------------------------------------
\section{Journal--institution citation networks}
\label{sec:networks}
% ---------------------------------------------------------------

We begin by selecting $N_s$ sources $\mathfrak{S}$ in a field, discipline or category.
Then we select $N_w$ works $\mathfrak{W}$ published in $\mathfrak{S}$ within the census
window years $t_c = [t^c_0 \ldots t^c_1]$ or target years $t_t = [t^t_0 \ldots t^t_1]$.
From the reference lists of the set of census works $\mathfrak{W}^c$ we identify the set of target works $\mathfrak{W}^t$ and form the filtered reference set $\mathfrak{R}=\{(i,j):w_i\in\mathfrak{W}^c,\,w_j\in\mathfrak{W}^t\}$.
Author affiliations in $\mathfrak{W}$ establish a set of authors $\mathfrak{A}'$ and institutions $\mathfrak{U}'$.
In practice many institutions (and sources) publishing only a few works per year can be dropped from the corpus.
Let $\bar{w}_u$ be the mean annual census-window work count for institution $u$ and $\bar{w}_s$ the corresponding count for source $s$.
We determine lower limits $\tau_U$ and $\tau_S$ by examining the respective frequency distributions and define
$\mathfrak{U}\subseteq\mathfrak{U}'$ as the institutions with $\bar{w}_u\geq\tau_U$,
and $\mathfrak{S}\subseteq\mathfrak{S}'$ as the sources with $\bar{w}_s\geq\tau_S$,
with corresponding author set $\mathfrak{A}\subseteq\mathfrak{A}'$.
Works that lose all their authorships under the institution filter, or whose source is dropped by the source filter, are removed from the corpus.
Each retained work $w_i$ has an \textit{institution weight} under author-fractional counting
\citep{waltmanFieldnormalizedCitationImpact2015},
\begin{equation}
  \omega_{i u} \;=\;
  \sum_{\ell:\,u\in\mathcal{u}_{i\ell}}
  \frac{1}{a_i}\,\frac{1}{u_{i\ell}},
  \label{eq:omega}
\end{equation}
where $\ell$ indexes the retained authors of work $w_i$, $a_i$ is their count, and $u_{i\ell}$ the number of
retained institutions of author $\ell$, so that $\sum_u\omega_{iu}=1$. Re-weighting fractional counts as a consequence of pruning the number of institutions is a trade-off between boosting a work's remaining institutions and diminishing the work's total contribution. 

Each reference $(i,j)\in\mathfrak{R}$ is a transaction between works:
the referencing work gives, and the referenced work receives. Correspondingly, the
units (source and institutions) of the referencing work transact with the units
of the referenced work, according to weights defined in the citation matrix $\mathbf{C}$
defined below.

We attach the construct \textit{attention} to these unit-to-unit transactions.

We then assert that the attention a unit gives should itself be amplified
or diminished by the attention that unit has received: a reference from a
highly-attended unit carries more weight than one from a lightly-attended
unit.
This leads directly to the eigenvector equation, in which the attention
of each unit is defined recursively as the weighted sum of the attention
of the units that reference it, with its value established only by the
convergence of that recursion.
The process of finding the fixed point is \textit{spectral ranking}
(a verb); the resulting vector is the \textit{spectral ranking} (a noun).
The vector can be read from either side of the transaction --- from the
referencing side as attention, or from the cited side as influence --- just
as $\mathbf{C}$ can be called a reference matrix or a citation matrix
depending on which side one stands.

A work with many references distributes its attention thinly across its
reference list; one with few concentrates it.
Let $R_i=|\{j:(i,j)\in\mathfrak{R}\}|$ be the reference count of work
$w_i$ and $\bar{R}=|\mathfrak{R}|/N_w$ the mean reference count over
$\mathfrak{W}$.
The \textit{attention weight} $\rho_i$ controls the total attention each
work contributes, balancing the amounts of attention across works
\citep{zittModifyingJournalImpact2008}:
\begin{equation}
	\rho_i \;=\;
	\begin{cases}
		 1 & \text{(full count: attention proportional to reference count)} \\
		\bar{R}/R_i & \text{(fixed count: equal total attention per work).}
	\end{cases}
	\label{eq:rho}
\end{equation}
Under full count a work with twice as many references contributes twice
as much total attention; under fixed count every work contributes the
same total attention $\bar{R}$, so that prolific citers do not dominate
the matrix.

We construct the set of \emph{units} [sources or institutions;
\cite{pinskiCitationInfluenceJournal1976}]
$\mathfrak{P}=\mathfrak{S}\ \cup\ \mathfrak{U}$ with $N=N_s+N_u$ elements,
ordered so that sources occupy indices $1,\dots,N_s$ and institutions
indices $N_s+1,\dots,N$.
Each reference $(i,j) \in \mathfrak{R}$ carries attention from the
units associated with $w_i$ to the units associated with $w_j$,
across four unit-type pairs: source--source ($SS$), source--institution
($SI$), institution--source ($IS$), and institution--institution ($II$).

For each work $w_i$ we define the source membership one-hot vector
$\mathbf{b}^S_i\in\mathbb{R}^{N_s}$ with $[\mathbf{b}^S_i]_s=\mathbf{1}[w_i\in s]$,
and the institution weight distribution vector
$\mathbf{b}^U_i\in\mathbb{R}^{N_u}$ with $[\mathbf{b}^U_i]_u=\omega_{iu}$
from \eqref{eq:omega}.
The attention carried by each reference is distributed across unit-type
pairs and accumulated as four block matrices over $\mathfrak{R}$ via
rank-1 outer products,
\begin{equation}
	\mathbf{C}_{XY} \;=\; \sum_{(i,j)\,\in\,\mathfrak{R}}
	\rho_i\;\mathbf{b}^X_i\,\bigl(\mathbf{b}^Y_j\bigr)^\top,
	\qquad XY\in\{SS,\,SI,\,IS,\,II\},
	\label{eq:Cblock}
\end{equation}
where $\mathbf{b}^X_i$ distributes attention from the citing side across
units of type $X$, and $\mathbf{b}^Y_j$ distributes it to the cited side
across units of type $Y$.
Each entry $[\mathbf{C}_{XY}]_{pq}$ is therefore the total
$\rho_i$-weighted attention flowing from unit $p$ of type $X$ to unit
$q$ of type $Y$ across all references in $\mathfrak{R}$.

The citation matrix assembles the four blocks:
\begin{equation}
	\mathbf{C}(\chi,\mathbf{m},\rho) \;=\;
	\begin{bmatrix}
		m_{SS}(1-\chi)^2\,\mathbf{C}_{SS} &
		m_{SI}\,\chi(1-\chi)\,\mathbf{C}_{SI} \\[4pt]
		m_{IS}\,\chi(1-\chi)\,\mathbf{C}_{IS} &
		m_{II}\,\chi^2\,\mathbf{C}_{II}
	\end{bmatrix},
	\label{eq:C}
\end{equation}
where the binary \textit{block mask} $\mathbf{m}=(m_{SS},m_{SI},m_{IS},m_{II})\in\{0,1\}^4$
is bibliometrically meaningful for
source-only $(1000)$, institution-only $(0001)$,
bipartite $(0110)$, and full-joint $(1111)$ combined blocks.
The mixing weight $\chi$ controls the source--institution balance
in the bipartite and full-joint cases and is inert in the single-mode cases.
The $\chi$ scaling preserves total attention flow across all block combinations,
since $(1-\chi)^2+2\chi(1-\chi)+\chi^2=1$.

Note that the corpus excludes (a) census work references not giving
attention to target works, (b) non-census works giving attention to
target works, and (c) authorships that include an omitted institution.

\paragraph{Ordinal spectral ranking.}
Let $r_p=\sum_q C_{pq}$ be the total weighted attention given by unit $p$
across all its references, and $\mathbf{D}_r=\mathrm{diag}(r_p)$ the
corresponding diagonal matrix.
Row-normalising $\mathbf{C}$ to obtain $\mathbf{H}=\mathbf{D}_r^{-1}\mathbf{C}$
ensures that each unit's references are equally valued regardless of how
many references it makes: a unit with many references exerts no more
attention per reference than one with few.
Size dependence is deliberately removed at this stage and reintroduced
only at the end via the influence per work scaling \eqref{eq:vstar}.
If $r_p=0$ (a dangling unit with no outgoing references) the corresponding
row of $\mathbf{H}$ is defined to be zero.

The three unipartite masks---source-only $(1000)$, institution-only $(0001)$,
and full-joint $(1111)$---each yield a square $\mathbf{H}$ to which the
following spectral ranking theory applies directly.
The spectral ranking $\boldsymbol{\pi}^*$
\citep[see][for an overview]{vignaSpectralRanking2016}
is the unique positive solution to the eigenvector equation,
\begin{equation}
    (\mathbf{I} - \mathbf{H}^\top)\boldsymbol{\pi}^* = \mathbf{0},
    \qquad
    \mathbf{1}^\top\boldsymbol{\pi}^*=1,
    \quad
    \boldsymbol{\pi}^*\ge 0,
    \label{eq:eig}
\end{equation}
when $\mathbf{H}$ is primitive (irreducible and aperiodic), as guaranteed
by the Perron--Frobenius theorem. Our implementation tests primitivity
for every $\mathbf{H}$ before applying the power iteration and has not
encountered a failure.
\cite{gellerCitationInfluenceMethodology1978} shows that
$\boldsymbol{\pi}^*$ is the stationary distribution of the
Markov chain with transition matrix $\mathbf{H}$, and that it coincides
with the \textit{influence weight} of \cite{pinskiCitationInfluenceJournal1976}
scaled by the reference count proportion $r_p / \sum_q r_q$.

\cite{katzNewStatusIndex1953} proposed attenuating influence along walks
of length $k$ by a factor $\alpha^k$, $\alpha\in(0,1)$, so that distant
endorsements count for less than proximate ones.
Summing attenuated walks of all lengths and endowing every unit with a
uniform initial score of $1$ yields the resolvent equation
\[
    (\mathbf{I} - \alpha\mathbf{H}^\top)\boldsymbol{\pi} = \mathbf{1}.
\]
Since $\mathbf{H}$ is row-stochastic, $(\mathbf{I}-\alpha\mathbf{H}^\top)$
is invertible for any $\alpha\in(0,1)$, guaranteeing a unique solution.

\cite{hubbellInputoutputApproachClique1965} generalised this by replacing
the uniform endowment $\mathbf{1}$ with an informative prior
$\boldsymbol{\mu}$ over units, representing exogenous information about
standing independent of citation structure,
\[
    (\mathbf{I} - \alpha\mathbf{H}^\top)\boldsymbol{\pi} = \boldsymbol{\mu}.
\]
We use the uniform prior $\mu_p = 1/N_{\mathfrak{P}}$ for $p\in\mathfrak{P}$.
The case $(\mathbf{I}-\alpha\mathbf{H}^\top)\boldsymbol{\pi}=\mathbf{0}$
with $\alpha\ne 1$ admits only the trivial solution $\boldsymbol{\pi}=\mathbf{0}$
and is not useful as a ranking.

Combining path attenuation and prior information yields the general
resolvent equation
\begin{equation}
    (\mathbf{I} - \alpha\mathbf{H}^\top)\boldsymbol{\pi}
    \;=\;
    (1-\alpha)\boldsymbol{\mu},
    \qquad
    \mathbf{1}^\top\boldsymbol{\pi}=1,
    \quad
    \boldsymbol{\pi}\ge 0,
    \label{eq:spectral}
\end{equation}
which recovers $\boldsymbol{\pi}^*$ in the limit $\alpha\to 1$ when
$\mathbf{H}$ is primitive.
While $\alpha$ and $\boldsymbol{\mu}$ are introduced here for their
substantive interpretations---path attenuation and exogenous prior
respectively---they have the additional effect of ensuring a unique
solution to~\eqref{eq:spectral} even when $\mathbf{H}$ is not primitive:
$\alpha<1$ makes $(\mathbf{I}-\alpha\mathbf{H}^\top)$ invertible, and a
nonzero $\boldsymbol{\mu}$ lifts the equation off the homogeneous system.

The spectral ranking $\boldsymbol{\pi}$ reflects the total influence of each unit and depends on unit size.
The \emph{influence per work} \citep{palacios-huertaMeasurementIntellectualInfluence2004},
\begin{equation}
    \mathbf{v}
    \;=\;
    A\,\mathbf{A}^{-1}\boldsymbol{\pi},
    \qquad
    \mathbf{A}=\mathrm{diag}(a_p),
    \qquad
    A = \mathbf{a}^{\top}\mathbf{1} = \textstyle\sum_p a_p,
    \label{eq:vstar}
\end{equation}
removes this dependence, where the unit work count $a_p = |\{i:w_i\in p\}|$ where $p$ is a specific source or institution,
and $\boldsymbol{\pi}$ denotes the solution to \eqref{eq:spectral}.
The scalar $A$ normalises $\mathbf{v}$ so that its $a_p$-weighted mean equals one:
$\mathbf{a}^{\top}\mathbf{v}/A=\mathbf{1}^{\top}\boldsymbol{\pi}=1$.
A unit with $v_p=1$ therefore has the corpus-average influence per work and
$v_p=2$ indicates twice the average influence per work.
\cite{palacios-huertaMeasurementIntellectualInfluence2004} show that
$\mathbf{v}$ is uniquely characterised by several reasonable axiomatic
constraints \citep[but see][]{serranoMeasurementIntellectualInfluence2004}.

\paragraph{Bipartite ranking.}
With $\mathbf{m}=(0110)$, equation~\eqref{eq:C} yields block off-diagonal matrices $\mathbf{C}$ and $\mathbf{H}$,
forming a directed bipartite network between sources~($S$) and institutions~($I$).
This is the mask used as the baseline model in Section~\ref{sec:results}.
Partitioning rows and columns into the $S$ and $I$ blocks, the stochastic matrix takes the form
\begin{equation}
  \mathbf{H}
  \;=\;
  \begin{pmatrix} \mathbf{0} & \mathbf{H}_{SI} \\ \mathbf{H}_{IS} & \mathbf{0} \end{pmatrix},
  \label{eq:H_bipartite}
\end{equation}
where $\mathbf{H}_{SI}$ distributes a source's attention across institutions and
$\mathbf{H}_{IS}$ does the reverse.
Because every path alternates $S\to I\to S\to\cdots$, this structure makes $\mathbf{H}$
periodic with period~2; the resolvent equation~\eqref{eq:spectral} ensures a unique
solution for any $\alpha\in(0,1)$.

Squaring $\mathbf{H}$ collapses the two-step walks back onto each node type, giving the
block-diagonal one-mode projections
\[
  \mathbf{H}^2
  \;=\;
  \begin{pmatrix} \mathbf{M}_S & \mathbf{0} \\ \mathbf{0} & \mathbf{M}_I \end{pmatrix},
  \qquad
  \mathbf{M}_S = \mathbf{H}_{SI}\mathbf{H}_{IS},
  \quad
  \mathbf{M}_I = \mathbf{H}_{IS}\mathbf{H}_{SI}.
\]
Both $\mathbf{M}_S$ and $\mathbf{M}_I$ are row-stochastic products of row-stochastic matrices.

To make the bipartite mode directly comparable with the unipartite SS and II modes at the same
$\alpha$, each single arc $SI$ or $IS$ is damped by $\sqrt{\alpha}$, so every
round-trip through $\mathbf{M}_S$ incurs attenuation $\sqrt{\alpha}\cdot\sqrt{\alpha}=\alpha$,
matching the single-step damping elsewhere.
Substituting $\sqrt{\alpha}$ for $\alpha$ in equation~\eqref{eq:eig},
partitioning $\boldsymbol{\pi}=(\boldsymbol{\pi}_S,\boldsymbol{\pi}_I)$,
and eliminating $\boldsymbol{\pi}_I$ yields the bipartite resolvent for sources,
\begin{equation}
  \bigl(\mathbf{I}-\alpha\mathbf{M}_S^\top\bigr)\boldsymbol{\pi}_S
  \;=\;
  (1-\sqrt{\alpha})\bigl(\boldsymbol{\mu}_S+\sqrt{\alpha}\,\mathbf{H}_{IS}^\top\boldsymbol{\mu}_I\bigr),
  \label{eq:kh_source}
\end{equation}
where the right-hand side transports institution prior mass back to sources through
$\mathbf{H}_{IS}^\top$.  The institution scores are then recovered by a single
matrix--vector product,
\begin{equation}
  \boldsymbol{\pi}_I
  \;=\;
  \sqrt{\alpha}\,\mathbf{H}_{SI}^\top\boldsymbol{\pi}_S+(1-\sqrt{\alpha})\boldsymbol{\mu}_I.
  \label{eq:kh_inst}
\end{equation}


\paragraph{Computation.}
To compute $\boldsymbol{\pi}$ we define the modified matrix
\begin{equation}
	\mathbf{\tilde{H}}
	\;=\;
	\alpha\mathbf{H}+(1-\alpha)\boldsymbol{\mu}\mathbf{1}^\top,
	\label{eq:Hstar}
\end{equation}
so that the fixed-point condition
$\boldsymbol{\pi}=\mathbf{\tilde{H}}^{\top}\boldsymbol{\pi}$
is equivalent to equation~\eqref{eq:spectral}.
Because $\boldsymbol{\mu}>0$ and $0<\alpha<1$, every entry of $\mathbf{\tilde{H}}$
is strictly positive, ensuring it is a primitive row-stochastic matrix.
By the Perron--Frobenius theorem, $\mathbf{\tilde{H}}^{\top}$ therefore
has a unique stationary distribution $\boldsymbol{\pi}$, recovered by
power iteration
\begin{equation}
	\boldsymbol{\pi}^{(k+1)}
	\;=\;
	\mathbf{\tilde{H}}^{\top}\boldsymbol{\pi}^{(k)},
	\label{eq:power}
\end{equation}
converging to $\boldsymbol{\pi}$ from any strictly positive starting
vector $\boldsymbol{\pi}^{(0)}$. The scaling $A\,\mathbf{A}^{-1}$ to
obtain $\mathbf{v}$ is applied after $\boldsymbol{\pi}$ has converged.

$\mathbf{C}(\chi,\mathbf{m},\rho)$ is a sparse matrix built from a
weighted edge list $\mathcal{E}$ accumulated over $\mathfrak{R}$ with
per-reference weight $\rho_i$, stored in CSR format, and
row-normalised to $\mathbf{H}$. The pipeline
$\mathfrak{R}\!\to\!\mathcal{E}\!\to\!\mathbf{C}\!\to\!\mathbf{H}
\!\to\!\boldsymbol{\pi}\!\to\!\mathbf{v}$
is implemented using \texttt{scipy.sparse.csr\_matrix} with parameter
entry points detailed in the Supplement.
